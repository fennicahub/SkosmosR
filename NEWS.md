# SkosmosR 0.1.0

- General Skosmos REST v1 client.
- High-level JSON endpoints now return tibbles consistently; nested structures are preserved as list-columns.
- Added explicit vocabulary- and concept-RDF helpers while retaining the low-level `skosmos_request()` escape hatch.
- Expanded validation of scalar vocabulary IDs and URIs for clearer errors.
- Expanded public-instance registry and vignette examples.
